# Media credits

This student application contains ten short excerpts from real podcast episodes. Mick Mouse is an independent classroom project and is not affiliated with, sponsored by, or endorsed by Jupiter Broadcasting, its hosts, or its guests. The original episode titles and hosts are retained. Cover illustrations and the application brand are original demo artwork, not official show artwork.

Each bundled MP3 contains **20 seconds from 05:00 to 05:20** of its source recording. Files were excerpted and re-encoded as mono, 44.1 kHz, 64 kbit/s MP3. They are playback/upload fixtures, not complete podcast episodes. The catalogue duration is the full original episode duration, rounded up to a minute; the player must identify the bundled audio as a short excerpt. Follow the source link to hear the full recording.

## Playback fixture verification

All ten files were extracted from the official show download sources and successfully decoded with FFmpeg. FFprobe verified MP3 audio, one channel, 44.1 kHz and approximately 20 seconds per file. The package includes about 1.61 MB of audio. This verifies usable audio fixtures; it does not verify S3, AWS permissions, or live deployment.
